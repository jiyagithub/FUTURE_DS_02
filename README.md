# TELCO CUSTOMER CHURN ANALYSIS DASHBOARD

## Overview

This project focuses on analyzing customer churn behavior in the telecommunications industry using Tableau Public. The objective is to identify key factors influencing customer retention and customer attrition, helping businesses make data-driven decisions to improve customer satisfaction and reduce revenue loss.

## Tools Used

* Tableau Public
* Microsoft Excel

## Dataset

* Telco Customer Churn Dataset (Kaggle)
* Customer demographics, service subscriptions, billing information, and churn status

## Key Features

* Interactive Tableau Dashboard
* KPI Cards (Total Customers, Churn Rate, Churned Customers, Average Monthly Charges, Average Tenure)
* Churn Analysis by Contract Type
* Churn Analysis by Internet Service
* Churn Analysis by Payment Method
* Churn Analysis by Tenure Group
* Churn Analysis by Tech Support
* Churn Analysis by Online Security

## Key Insights

* Month-to-month customers show the highest churn levels.
* Fiber optic customers exhibit higher churn compared to DSL users.
* Customers without tech support are more likely to leave the service.
* Customers without online security demonstrate higher churn rates.
* Electronic check users experience higher churn than customers using automatic payment methods.

## Recommendations

* Promote long-term contracts through discounts and loyalty programs.
* Encourage customers to adopt online security services.
* Offer tech support bundles to improve customer retention.
* Target high-risk customer segments with personalized retention campaigns.
* Implement early intervention strategies for customers likely to churn.
